## Usage
All JBDesign System Component initial their needed variables themselves and you don't need any initialization to use our components. **But** if you need these variables for your own elements you can initialize them like this:

```javascript
import {defineSizes} from 'jb-core/theme';
// it will define all size, radius and corner shape css variables in @property and :root you can also customize them in your css
defineSizes();
```

`--jb-corner-shape` is registered by `defineSizes()` and components register it too when they call `registerDefaultVariables()`.

## corner shape

jb design system by default has Modern and Round corners. the radius of these corners is set by the radius tokens documented in [Theme/Sizes](?path=/docs/theme-sizes--docs) and the **shape** of the corner inside that radius is set by the standard `--jb-corner-shape` token, which mirrors the `corner-shape` css property.

`corner-shape` only changes the corner area that is cut by `border-radius`, so it has no visual effect on a corner with a radius of `0`.

### corner shape values

the value of the token is a single `<corner-shape-value>` that applies to all four corners:

<table>
  <thead>
    <tr>
      <th>Value</th>
      <th>Shape</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>round</code></td>
      <td>default</td>
      <td>the regular rounded corner that you already know from <code>border-radius</code>.</td>
    </tr>
    <tr>
      <td><code>square</code></td>
      <td>right angle</td>
      <td>keeps the corner perfectly right-angled even when a radius is applied.</td>
    </tr>
    <tr>
      <td><code>squircle</code></td>
      <td>square + circle</td>
      <td>a shape between a square and a rounded corner, the so-called superellipse of a squircle.</td>
    </tr>
    <tr>
      <td><code>bevel</code></td>
      <td>flat cut</td>
      <td>cuts the corner diagonally and produces a flat edge.</td>
    </tr>
    <tr>
      <td><code>scoop</code></td>
      <td>concave</td>
      <td>creates an inward (concave) quarter ellipse.</td>
    </tr>
    <tr>
      <td><code>notch</code></td>
      <td>sharp inward</td>
      <td>produces a sharp inward corner.</td>
    </tr>
    <tr>
      <td><code>superellipse(k)</code></td>
      <td>custom curve</td>
      <td>lets you pick your own curve with a numeric value. positive values round the corner outward and negative values scoop it inward, for example <code>superellipse(0.6)</code>.</td>
    </tr>
  </tbody>
</table>

### set the token

the shared token is the recommended place to declare one corner shape for the whole app:

```css
:root {
  --jb-corner-shape: scoop;
}
```

there is no default value written on the `html` element for this token (its `round` default comes from the `@property` initial value), so a `:root` declaration takes effect normally.

you can also scope it to a part of your app, the same way as every other inherited css variable:

```css
.my-panel {
  --jb-corner-shape: bevel;
}
```

<div style={{"--jb-corner-shape": "scoop", display: "grid", gap: "1rem", padding: "2rem", borderRadius: "var(--jb-radius, 1rem)", background: "var(--jb-surface-secondary, #f7f8fb)"}}>

### corner shape in components

components that support corner shaping expose their own part variable and use the standard token (or the component family token) as its default, exactly like the color and shadow variables. `jb-color-input` is the component that supports it today:

```css
/* inside a component stylesheet, for example jb-color-input variables.css */
:host {
  --color-corner-shape: var(--jb-color-input-corner-shape, var(--jb-input-corner-shape, round));
}
```

so you can set the standard token for the whole app, or map it to the component level variables to keep component specific corner shapes:

```css
:root {
  --jb-corner-shape: squircle;
  /* let the color input follow the shared corner shape */
  --jb-color-input-corner-shape: var(--jb-corner-shape);
}

/* or only change one component */
jb-color-input {
  --jb-color-input-corner-shape: notch;
}
```

### browser support

`corner-shape` is an experimental property and is not part of the browsers Baseline yet. Chromium based browsers support it since version 139 (August 2025) while Firefox and Safari do not support it yet.

because of that:

- browsers without support ignore the `corner-shape` declaration and keep the regular rounded corner that `border-radius` produces, so it is a safe progressive enhancement.
- always read the token with a fallback (`corner-shape: var(--jb-corner-shape, round)`) so the declaration stays valid on every browser. in browsers that do not know the `<corner-shape-value>` syntax the `@property` registration of the token is skipped, so the fallback is what keeps the default shape.
- the token is a single value for all four corners. if you need a different shape per corner, set the `corner-shape` property directly with up to four values, ordered clockwise from the top-left corner, for example `corner-shape: scoop round bevel notch;`.
